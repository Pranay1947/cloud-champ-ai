# Cloud Champ AI — Pilot Plan

## Phase 1 — Corpus
Process 20–50 representative videos:
- 10 long-form tutorials
- 10 practical/project videos
- 5–10 interview/certification videos
- 5–10 Shorts

## Phase 2 — Retrieval
Evaluate questions such as:
- What is Kubernetes?
- What is a Pod?
- Docker vs Kubernetes?
- What is Terraform state?
- How does CI/CD work?
- Explain an AWS VPC.
- Give me a DevOps interview question.

Success criteria:
- correct source retrieval
- answer grounded in source
- useful video links
- no invented claims

## Phase 3 — Style
Create a style profile from representative transcripts:
- opening pattern
- explanation order
- recurring terminology
- level of detail
- examples
- interview framing
- call-to-action patterns

## Phase 4 — Chatbot
Add:
- semantic search
- reranking
- LLM response generation
- source citations
- conversation memory

## Phase 5 — Content copilot
Add:
- video scripts
- Shorts scripts
- titles
- descriptions
- chapter generation
- quiz/interview questions

## Phase 6 — Voice/video
Only after the text system is reliable:
- approved voice model
- avatar/digital presenter
- lip-sync/video generation
- disclosure that the content is AI-generated
